缝纫机经销商小程序 API · 接口文档

缝纫机经销商小程序 API 小程序 / 师傅端 / 商家后台共用的 HTTP 接口契约，共 34 个接口、188 个数据模型。
金额字段一律为整数「分」；响应统一为 {code, msg, data, traceId}， code = 0 为成功。鉴权用 Authorization: Bearer <JWT>。

环境

本地 Mock / 开发环境http://127.0.0.1:8080
生产环境https://api.example.com

本地联调：python3 api/mock_server.py 8080 即可启动 Mock 服务， 小程序端把 config.js 的 USE_MOCK 设为 false 并打开开发者工具 「不校验合法域名」即可直连。

仅 Mock 环境额外提供 POST /api/pay/mock-success：模拟微信支付成功回调， 用于在开发者工具里跑通「支付 → 状态推进」而不需要真实商户号。生产环境不存在该接口， 订单状态只认微信异步通知。

错误码

code含义前端处理建议
0成功—
1001参数错误提示具体字段，不弹通用错误
2001未登录 / token 过期静默重新 wx.login，再重放原请求
2003无权限提示后返回上一页
3001库存不足引导改选机型或「到货通知」
3002师傅档期冲突展示可选日期与备选师傅
3003订单状态不允许该操作刷新订单详情
3004金额校验失败刷新订单金额后重试
3005打卡距离超限提示「请在客户地址 500 米内打卡」
4001重复请求（幂等命中）直接使用返回结果，不重复提示
5001支付下单失败重试 + 客服入口

订单

POST/api/orders

提交订单

金额由服务端按 SKU 与定金比例计算，前端传的金额仅做校验比对。
提交时校验库存与师傅档期；任一不满足返回 3001 / 3002。
接口幂等：同 requestId 10 分钟内重复提交返回同一订单。

请求体（application/json）

字段类型必填说明
requestIdstring是幂等键
skuIdinteger是
quantityinteger是
addressIdinteger是
installDatestring是
installSlotstring enum是
technicianIdinteger否不传则系统派单
remarkstring否
invoiceobject否

请求示例

{
  "requestId": "8f1c2e4a-6b7d-4c1e-9a2f-1d3e5b7c9a01",
  "skuId": 1011,
  "quantity": 1,
  "addressId": 55801,
  "installDate": "2025-11-28",
  "installSlot": "AM",
  "technicianId": 88,
  "remark": "厂房在 3 楼，有货梯",
  "invoice": {
    "need": true,
    "title": "杭州某某服饰有限公司",
    "taxNo": "91330100MA2XXXXX"
  }
}

响应

200 下单成功，返回待支付订单

400 2001 参数错误 / 3001 库存不足 / 3002 档期冲突 / 4001 重复请求
